# Getting Started
Set up the cdss-testing-harness for usage

1. Install Docker and NodeJs

* [Docker](https://docker.com)
* [Node.js](https://nodejs.org/en/) (v20.15.1 used for development)


2. Download the repository or clone the repository

```bash
git clone https://github.com/CDSS4PCP/cdss-testing-harness.git
```

3. Cd into the downloaded or cloned repository

```bash
cd cdss-testing-harness
```

4. Install the dependency packages

```bash
npm install 
```

5. Run tests

```bash
npm run test-cql
```
